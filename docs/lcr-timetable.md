# 老中铁路时刻表

在线车次查询使用 [Laos Bus Tickets 发布的时刻表](https://laosbustickets.com/train-tickets-laos/#timetable)，原始数据为 [JSON](https://laosbustickets.com/data/laos-train-timetable.json)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本站将车站名称转换为中文，并提供北京时间与万象时间的显示切换。中文站名参考[国家发展改革委公布的中老铁路老挝段客运站](https://www.ndrc.gov.cn/fggz/lywzjw/202206/t20220629_1374240.html)。

- 只接入老挝段的非 D 字头车次，以每条记录的 `runsOn` 匹配始发日期。发布方目前提供滚动 7 日时刻。国内查询和路路通离线查询仍按各自的日期范围运行。
- 同一日期存在同号线路时，查询结果可切换线路。C85、C86 优先显示 12306 的昆明与香格里拉之间的班次。所选日期查不到 12306 班次时，直接显示可查到的老挝班次。
- 每个服务进程缓存一次成功下载。万象时间每天 06:05 后的首次查询检查更新，并合并并发下载。上游未更新或请求失败时，15 分钟后可重试，仍在缓存日期范围内的班次可以继续查询。
- 老挝段源时刻为万象时间。页面默认显示万象时间，切换到北京时间时加一小时。
- 老挝段里程取自用户提供的 D88 经由里程表。万象、蓬洪、万荣、嘎西、琅勃拉邦、孟阿、孟赛、纳磨、纳堆、磨丁的线路里程依次为 0、64、123、167、239、293、339、378、394、406 公里。各站显示与该车次始发站的线路里程差的绝对值，始发站为 0 公里。

## 离线时刻表

车次列表、离线车次查询和老挝段车站大屏读取独立的 `server/db/lcr-offline.json`。快照保存 GMT+8 到发时刻、跨日数及累计里程。离线车次详情默认显示万象时间，可切换到北京时间。大屏直接使用万象时间。

开行区间两端均包含。C85、C86、C91、C92 每日开行，C95 周五至下周二，C96 周四至下周一，均为 2026-11-01 至 2027-01-15。K11、K12 为 2026-11-01 至 2026-11-24，周三至周六开行。D 字头车次沿用其他数据源。

更新前按新运行图维护 `data/lcr-offline-rules.json`，然后运行 `node scripts/update-lcr-offline.js`。命令也可接受已保存的源 JSON 路径，例如 `node scripts/update-lcr-offline.js timetable.json`。脚本检查每个开行星期都有明确的源时刻，成功后原子替换快照，服务会自动读取新文件。更新路路通或在线时刻缓存都不会写入此快照。
