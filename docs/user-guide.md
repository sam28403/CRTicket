## 余票监控的车次筛选

余票监控的“普速列车”筛选采用规则 1。表中的号段包含起止车次。

| 字头 | 车次范围 |
| --- | --- |
| Z、N、V、Y | 字头后接数字的车次 |
| D | D1 至 D300、D701 至 D800 |
| C | C1 至 C999、C4001 至 C4699 |
| S | S101 至 S999、S1001 至 S2999 |

其余车次在余票监控中归入“高速动车”筛选，例如 T、K 字头车次。车票制作和票价计算各自采用独立的车次规则。
