## 数据与静态部署

首页演示使用的字符放在优先匹配的小分片中，其他字符由对应范围的分片提供。
制票和正式监控页面共用同一组分片。原始字体保留在 `public/`。

修改车票或余票演示文案、样例数据后，安装 Python 的 `fonttools` 和 `brotli`，
再运行 `python scripts/build-web-fonts.py`。
提交生成的 `src/assets/fonts/` 和 `src/assets/styles/ticket-fonts.css`。
脚本会校验每个分片的字符覆盖和横向字形度量。

保留重复记录和未来日期，次数按记录数累计；里程缺失不估算。

地图只加载 public/maps 下的静态 JSON 文件，不依赖 API 或外部地图服务。
